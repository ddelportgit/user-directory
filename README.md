# User Directory

A responsive user directory that fetches user data from an API and allows users to search by name, email, or city.

## Features

- Fetches users from JSONPlaceholder API
- Displays user names, email addresses, and cities
- Searches users in real time
- Shows the number of matching users
- Handles loading, errors, and empty results
- Responsive card layout

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- JSONPlaceholder API

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
